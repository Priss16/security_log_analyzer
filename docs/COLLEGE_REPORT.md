# Security Log Analyzer: SentinelTrace AI
**College Submission Report**

## Abstract
Modern Security Operations Centers (SOCs) face alert fatigue and struggle to unify fragmented logs across diverse systems. This project, **SentinelTrace AI**, presents a comprehensive solution by building a modular log ingestion pipeline, a dynamic YAML-based rule engine, and an automated enrichment system mapped to the MITRE ATT&CK framework. 

## 1. Problem Statement
System administrators and security analysts are overwhelmed by the sheer volume of raw logs generated by SSH servers, Web servers (Apache/Nginx), and Windows environments. Without automated normalization, threat intelligence enrichment, and threshold-based alerting, critical attacks such as Password Spraying and SQL Injections often go unnoticed until post-breach forensics.

## 2. Methodology
The project was engineered using a modern cybersecurity software architecture:
- **Modular Ingestion:** Regular Expressions (Regex) were utilized to build custom parsers for raw Linux `auth.log` and Apache `access.log` formats.
- **Normalization:** Pydantic models enforce a strict schema, ensuring all logs—regardless of origin—share common fields (`source_ip`, `event_type`, `timestamp`).
- **Dynamic Detection:** A custom YAML engine was built to replace hardcoded logic. It maintains state in memory, allowing for complex time-series detections (e.g., 5 failed logins within 5 minutes).
- **Threat Intelligence:** An enrichment module intercepts normalized logs to append GeoIP data and check the source IP against a known malicious blocklist.

## 3. Results & Capabilities
The system successfully processes offline files and live directories. During simulated testing (using Hydra and SQLmap), the engine accurately detected:
1. **T1110.001 (Password Guessing):** Identified SSH brute force attacks.
2. **T1190 (Exploitation):** Identified SQL injection attempts via URI inspection.

Upon detection, the system successfully outputs HTML incident reports and generates precise `iptables` and `ufw` firewall commands for immediate incident response.

## 4. Conclusion
SentinelTrace AI demonstrates a portfolio-ready implementation of core SIEM (Security Information and Event Management) concepts. By decoupling parsers from the detection engine, it allows for infinite scalability. Future iterations will explore Machine Learning for anomaly detection beyond static signatures.
